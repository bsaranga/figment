The thesis

Developer experience

Keep your components. Add a surface.

Host owns paint, geometry, hits, and admission. Your framework keeps ownership of the tree.

app.ts@figment/host
import { createHost } from "@figment/host";

const host = createHost(stage, { backend: "2d" });
await host.admit();          // pixel + hit probes
host.mount(stage);

const panel = host.layer(form, {
  id: "profile",
  transform: { x: 24, y: 24 },
  origin: "center",
  preserveHitTestOrder: true,
});

// Scroll flies HTML through depth
// layer.setTransform({ z: -2400 }) + scrollTrack

Fail-fast, never fake

Missing capability throws FigmentUnsupportedError. No silent fallbacks, no broken UI.

Seamless first enable

Swap only when a complete frame exists. Users never see a blank flash on startup.

Admission, not sniffing

Known-color pixel readback + transformed elementFromPoint proofs before any GPU path.

Hit stack that behaves

preserveHitTestOrder, canvas clips, and pivot-correct rotation — clicks match pixels.
